# 🧩 Featured Projects

## 🤖 Multimodal WhatsApp Notification Router

### HackerRank Orchestrate 2026

Built an AI-powered multimodal notification routing system combining:

`OCR` `Whisper` `Semantic Analysis` `User Context` `Deterministic Rules` `LLM`

The system processes **text, images, and voice notes** and determines whether a message should be:

> 🔔 **Notify Immediately**  
> 🗂️ **Digest Later**  
> 🔇 **Mute**

The routing workflow considers message content, user behavior, group context, business relationships, historical interactions, and safety signals.
